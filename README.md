# 鸟类监测数据湖（Flask + PyArrow + SQLite）

把各监测站逐年新增鸟种的调查 CSV 入湖：每批一个独立 Parquet 文件，目录库（SQLite）
按列名合并出统一的逻辑结构，研究员可按站点预览 / 下载统一结构的 CSV。
另提供**同站同日重复调查核查页**：按站点 + 观测日分组找出重复取样，支持分页浏览
来源批次 / 文件名 / 批内数据行号，并可把组标记为已核查。

## 快速开始

```bash
docker compose up --build
# 打开 http://localhost:8000
```

可选：灌入示例数据（含一次「uint64 与 text 冲突 → 提升为 text」的演示）

```bash
docker compose exec web python scripts/seed_demo.py
```

运行端到端自检（解析校验 / 结构合并 / 类型提升 / 并发 / 重启持久化 / Web 流程）：

```bash
docker compose exec web python scripts/selftest.py
```

本地开发（不用 Docker）：

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
export DATA_DIR=./data
flask --app app.web run        # 或 gunicorn -b 0.0.0.0:8000 app.web:app
```

## 数据格式与入湖流程

1. **上传**：每批填写站点 + 选 CSV。CSV 首列为观测日（`YYYY-MM-DD`），其余每列一种鸟；
   列名去空白后非空且不得重复；空单元格一律按 NULL 处理。
2. **逐列声明类型**：每个鸟种列声明为 `uint64`（非负 64 位整数，0 ~ 2^64-1）或 `text`。
   首列观测日归一化为固定列名 `obs_date`（date 类型），鸟种列不得使用该保留名。
3. **发布**（同一写事务共同提交，失败整体回滚、不留半批）：
   - 解析校验（坏整数、坏日期、字段数不齐 → **整批不发布**）；
   - 写 `parquet/<批次UUID>.parquet`：先写临时文件 + fsync，再原子 rename，**既有文件永不重写**；
   - 最后才开启**短暂的**目录库写事务：合并逻辑结构 + 登记批次 + **整批观测索引**
     （`obs_index`：批内数据行号从 1 起）+ **撤销受影响（同站同日）组的核查标记**。
   解析和写文件期间**不持有**目录库写事务；登记失败会删掉未发布的文件，**目录永不引用残件**。

## 重复调查核查

导航栏「重复调查核查」（`GET /duplicates`）：

- 按**站点 + 观测日**分组，组内至少两条观测即列入清单；**完全相同的重复行也分别保留**
  （索引主键为 `批次 + 批内行号`），每行展示来源批次、源文件名、批内数据行号（从 1 起）与 Parquet 文件名；
- 分页展示（默认每页 20 组），可按站点过滤；
- 「标记为已核查」把组写入 `dup_checks`，表单携带页面渲染时的组内观测数 `expected_n`
  作为乐观并发令牌：组在页面打开后新增过观测时提交被拒并提示刷新，**旧页面无法标记已变化的组**；
- 组内新增任何观测时，发布事务会**自动撤销该组标记**，再次核查前研究员能看到它回到未核查状态；
- **不自动去重**：原 Parquet 与统一结构取数保持原样，重复行照常出现在预览 / 下载中。

### 首次后台补建历史索引

库首次初始化时进入 `backfilling` 态，由守护线程在后台扫描全部历史 Parquet：

- **扫描不占目录库写事务**：Parquet 读取在事务外完成，每个批次只做一次幂等的短写事务
  （整批索引 `INSERT OR IGNORE` + 推进补建游标），期间上传 / 预览 / 下载照常可用；
- **就绪前页面提示未完成**（每 3 秒自动刷新），且不允许打标记；
- 补建排空时在同一写事务内复检「游标之后无批次」才翻转 `ready`，
  因此**就绪时必然包含补建期间所有成功发布的批次**（这些批次在发布事务内已自行登记索引）；
- 游标、已完成索引与核查标记都持久化在库中，**重启后从未完成处接续**，已完成成果保留；
- 此后批次登记、整批索引与标记撤销在发布写事务内共同提交，每次查询只见同一完整状态。

## 逻辑结构合并规则

- 按列名合并；批次缺列在读出时补 NULL；新鸟种自动加列；
- 同鸟种类型冲突（一边 `uint64` 一边 `text`）→ 提升为 `text`；
- 提升后**不得退回**整数（`text` 是吸收态）；旧整数读出时按**十进制**转成文本；
- 并发上传新增不同鸟种、或对同列并发提升：发布事务经 `BEGIN IMMEDIATE` 串行化，
  结构变化与各批记录都完整保留（自检第 3 项覆盖）。

## 一致性读取

预览 / 下载在同**一个 SQLite 读事务**内取「逻辑结构 + 文件清单」快照（WAL 模式），
再按该快照读取不可变的 Parquet 文件——一次取数始终使用同一状态的结构与清单。
页面上的 `schema v<N>` 每次结构变化都会递增。

## 持久化与重启

`DATA_DIR`（Docker 卷 `lake_data`）内含 `catalog.db`（WAL）与全部 Parquet 文件。
重启后直接可用；启动时清理暂存区与崩溃遗留的临时文件，未被目录引用的孤儿
Parquet 过了宽限期才删除（不影响在途发布）。

## 目录结构

```
app/
  catalog.py    # SQLite 目录库：逻辑结构 + 批次清单 + 观测索引/核查标记，读写事务
  backfill.py   # 历史重复索引首次后台补建（事务外扫描、短事务登记、重启接续）
  csvparse.py   # CSV 解析与校验（纯标准库）
  store.py      # PyArrow：批次表构建、原子写 Parquet、统一结构读取、CSV 导出
  service.py    # 入湖编排：暂存 -> 校验 -> 写文件 -> 短事务登记/索引/撤标；启动清理与补建
  web.py        # Flask 路由：上传/声明/发布/预览/下载/重复核查
  templates/    # 页面（含 duplicates.html 重复调查核查页）
scripts/
  selftest.py   # 端到端自检（12 组：含重复索引、补建、乐观并发、重启接续、原子性）
  seed_demo.py  # 示例数据灌入
samples/        # 示例 CSV
```

## 主要 HTTP 入口

| 路由 | 说明 |
| --- | --- |
| `GET /` | 总览：逻辑结构、站点、批次、重复索引状态 |
| `GET/POST /upload` | 上传 CSV（第一步） |
| `POST /publish` | 声明类型后发布（第二步；同事务登记批次+索引+撤标） |
| `GET /preview?station=&limit=` | 按站点预览统一结构 |
| `GET /download.csv?station=` | 下载统一结构 CSV（可按站点过滤，不去重） |
| `GET /duplicates?station=&page=` | 重复调查核查页（补建未完成时提示未完成） |
| `POST /duplicates/mark` | 标记组为已核查（`expected_n` 乐观令牌，旧页面拒绝） |
| `POST /duplicates/unmark` | 撤销核查标记 |
| `GET /healthz` | 健康检查 |
